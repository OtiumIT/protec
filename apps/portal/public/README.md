# Assets públicos da landing

Arquivos aqui são servidos na raiz do site (ex.: `/hero-dashboard.png`).

Para a landing exibir imagens reais, adicione:

- `hero-dashboard.png` – screenshot ou ilustração do dashboard (Hero)
- `product-preview.png` – screenshot da listagem de clientes ou arquivos (seção Preview)

Se os arquivos não existirem, a landing exibe um placeholder.
